# Time-Frequency Analysis: Second Order Synchronous Extractive Transformation [with MATLAB Code]

This paper introduces a new method for processing non-stationary signals, the SSET method. This approach not only enables compact TFR but also allows for precise mode reconstruction. Simulation signals and vibration signals collected from an experimental rig validate the effectiveness of SSET. The results indicate that SSET is suitable for extracting time-frequency features of signals and can be used for fault diagnosis in rotating machinery. In future research, we will explore more application areas using SSET. Additionally, we are considering expanding the proposed method to handle two-dimensional signals.
